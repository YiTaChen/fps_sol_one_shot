# Ash Exchange 第二輪製作與驗證

《Saltline》的第一眼優勢來自視線終點、近景物件密度與受光材質。先前的 Cinderline 已建立完整任務，但沿用空間與大部分近景物件，開場仍容易被看成程序化原型。這輪以正式版主選單、部署出生點、第一段室內和露天維修區做畫面驗收。 [首輪比較](saltline-comparison.md) · [Saltline 原始展示](https://x.com/felixrieseberg/status/2119925633564463609)

| 檢查項目 | 本輪結果 |
| --- | --- |
| 第一眼可辨識的場景 | 主選單呈現實際 3D 場景。部署點退到可同時看見 Saffron 招牌、屋頂熱交換機、金屬雨棚和室內入口的位置。 |
| 貼近可見的材質與造型 | ImageGen 產生礦物水泥、濕瀝青、波紋鋼板和煙燻磚牆的原圖，裁製成遊戲 PBR 貼圖。Blender 產生有獨立轉軸的屋頂風扇、門廊和 North Service 冷凝機。Saffron 內部改成有夾層、線槽和配電櫃的交換站。 |
| 玩家決定如何過關 | 恢復第一、第二站的供電會打開不同的實體閘門。第三站點亮撤離區。每站補一次訊號誘餌，玩家可在離開中繼站後按 G 決定觸發時機，讓至多兩名符合條件的巡邏前往訊號位置。 |
| 操作與回歸 | 26 項檢查全通過。兩組種子驗證原路與新開的兩條通道。正式 Chrome 測到長按 F、實際鍵盤 G、一次性誘餌、重開重置與滑鼠鎖定。 |

原生 Chrome 在 1280×720 中畫質測試，同種子 90 幀暖機、360 幀取樣。三版皆為 37 次開火、1 次重裝，移動約 16 公尺。本輪顯示負載較上輪增加，中位幀率由 59.9 至 59.2 FPS，第 95 百分位幀時間由 18.5 至 20.7 ms，兩版皆沒有超過 50 ms 的幀。中低畫質會隔幀更新太陽陰影，畫面與輸入仍逐幀更新。 [效能樣本](performance/relay-run-comparison.json)

在上輪和本輪同鏡位截圖中，近景材料細節、路徑辨識和室內場景的用途更清楚。本輪可玩版本的供電與誘餌有可重現的玩法差異。Saltline 的近景設備密度和濕面反射仍較細膩。Cinderline 的敵人肢體和持槍手部仍顯簡化。兩款遊戲的整體名次仍需要同條件的實際比較。
