# Cinderline 軍械庫更新

製作依序處理角色輪廓與動作、裝備操作、投擲物、經濟循環和瀏覽器整合。兩種遊戲模式共用裝備欄與補給規則。

| 範圍 | 實作 |
| --- | --- |
| 敵人 | 四種工業區敵人外觀。頭盔、面罩、防護裝備和制服色調不同。補上護膝、手套、肘部與肩部細節，調整跨步、落地與受擊。 |
| 武器 | Vesper 自動步槍、Flicker 衝鋒槍、Meridian 狙擊槍、Ember 輕手槍、Cinder 重手槍、Arc Cutter 近戰工具。武器各有模型、操作節奏、移動修正和回饋。狙擊會顯示放大鏡與退鏡循環。近戰用遊戲中的距離和阻擋判定。 |
| 投擲物 | Pulse 削弱附近敵人、Haze 暫時阻擋敵人視線、Stasis 暫停附近敵人的動作。道具會在場景內飛行、碰撞並部署。掩體可阻隔 Pulse 和 Stasis。 |
| 商店與代幣 | 以 1,400 點開始，擊倒敵人 +125、恢復中繼站 +250、過關 +400。商店可在部署前、開場補給櫃和無近敵的已供電中繼站開啟。買下的武器在本次行動內可免費換裝，備彈補給可購買。 |
| 重開與無限清剿 | 重開回到該輪最初的裝備、道具和餘額，清除這次行動中賺到的點數。無限清剿過關後，裝備與餘額帶入下一輪。 |

### 操作

主選單點 **Armory** 可先選裝。部署後用 **B** 開啟附近的安全軍械庫。**1／2／3** 切換主武器、副武器、近戰。**4／5／6** 選擇 Pulse、Haze、Stasis，再按 **T** 投出。完整價格在 README。 [裝備與價格](../README.md#armory-and-credits) · [商店實際畫面](demo/armory.webp)

### 商品辨識與購買

CS2 將裝備集中在單一選購格，VALORANT 在商店保留武器詳情，Warzone 的購買介面用道具圖示與數量加快查找。 [CS2 更新](https://store.steampowered.com/news/app/730/view/3702568031467145905) · [VALORANT 更新](https://playvalorant.com/en-gb/news/game-updates/valorant-patch-notes-1-0/) · [Warzone 更新](https://www.callofduty.com/patchnotes/2025/03/call-of-duty-bo6-warzone-season-03-patch-notes)

Cinderline 將十件商品分組顯示，每張商品圖可開啟檢視。拖曳可旋轉遊戲模型，購買按鈕同步顯示價格、已裝備、點數不足或攜帶上限。武器詳情列出射擊模式、彈匣容量與移動速度，投擲物會顯示攜帶數量。點商品圖不會扣點。

### 驗證

- 使用相同的固定步模擬驗證六款武器的模型、連發與單發、狙擊鏡循環、切換時的彈藥及近戰遮擋。
- 投擲物測試覆蓋物理碰撞、掩體、霧幕視線、停滯到期和清理。
- 瀏覽器驗證購買、餘額不足、備彈補給、受威脅時鎖住補給櫃，以及重開還原。 [正式測試報告](tests/smoke-report.json)

敵人近處保留裝備細節，遠處簡化小配件和投影。在同一台 Mac 連續測試前版與本版的 720p 中畫質移動戰鬥，兩版中位幀率皆為 57.1 FPS，第 95 百分位幀時間分別為 20.6 和 20.4 ms。測試場景皆用預設步槍，包含 37 次開火與一次重裝。 [幀時間樣本](performance/armory-paired.json)
